# 黃名音樂廳

獨立的黃名帝國音樂廳網站。

## 功能
- 使用指定圖片作為音樂廳背景。
- 左側顯示 YouTube 曲目封面與清單。
- 點選曲目後在中央 YouTube 播放。
- `admin.html` 可在目前瀏覽器新增、刪除曲目。
- 預設曲目：天命所歸典禮曲。

## GitHub Pages
網站根目錄直接使用 `index.html`。

## 論壇嵌入
部署後可用 iframe 嵌入黃名論壇：
```html
<div style="width:100%;margin:0 auto;">
  <iframe src="https://annynn1990.github.io/wongming-music-hall/" style="display:block;width:100%;height:760px;border:0;" scrolling="no" title="黃名音樂廳"></iframe>
</div>
```
